## Phase E — Foreground self-audit (in parallel while agents run)

### E.1 — Commit-by-commit closure verify
Walk all 23 commits; for each, re-read the diff + confirm the original finding is closed. Detect any unintended side-effect.

### E.2 — Hono `c.req.query()` API check via context7
Verify `c.req.query('demo') === '1'` returns the correct shape. Hono returns `string | undefined`; equality check is safe but worth confirming.

### E.3 — React `useId()` semantics via context7
Verify `useId()` is stable across renders + SSR-safe. Confirm `:` stripping is necessary (React generates `:r0:` style).

### E.4 — curl Pages site verify
GitHub Pages serves Privacy + ToS. Verify HTTP 200 + body reflects the MHS scrub.

### E.5 — AutoMod hedge via WebSearch
Cross-check "Wright 2022 + Jhaver 2019" actually substantiate "AutoMod handles the majority of automated review surface." Don't want to hedge to a citation that doesn't actually say what we claim.

### E.6 — OG metadata actually reachable?
Reason through: Devvit iframe URL isn't a shareable surface. GitHub repo URL renders GitHub's OG. Where does our `src/client/index.html` ever get fetched by an OG crawler? If nowhere, H9 is dead code.

### E.7 — JSON5 examples parse-validity
Use Python JSON5 parser (or `json5` npm CLI) to confirm all 3 example configs parse without error.

### E.8 — README Comparison table fact-check
Each cell in the AutoMod column — does the public Reddit/AutoMod doc support the claim? Particularly "Age + karma threshold only" (might be limiting) and "Single-pass YAML matchers" (mostly true but YAML rules can include filter combinators).
