## Risk register

| Risk | Likelihood | Mitigation |
|------|-----------|------------|
| Node version compat (CommonJS .cjs) | Very low | .cjs extension forces CJS regardless of package.json type:"module" |
| Port 5173 already in use | Low | Devvit playtest uses different port; vite preview is blocked anyway. Logs error + exits clean |
| Static file path traversal | Low | path.join(DIST, url.pathname) — Node normalizes; but add explicit `..` check for safety |
| index.html SPA fallback breaks /api/* routing | Low | Order matters: check /api/* FIRST, fall through to static |
